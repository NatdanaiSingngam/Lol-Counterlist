# Rift Counter

เว็บภาษาไทยสำหรับดูคู่ที่ชนะทางและแพ้ทางของแชมเปียน League of Legends PC ทั้ง 173 ตัว แยกตามตำแหน่ง พร้อมค้นหาชื่ออังกฤษ ฉายาภาษาไทย และชื่อเรียกไทยที่รองรับ

## ใช้งาน

เป็นเว็บ static ไม่ต้องติดตั้งแพ็กเกจ ใช้เว็บเซิร์ฟเวอร์เปิดโฟลเดอร์นี้ เช่น `python -m http.server 8000` แล้วเปิด `http://localhost:8000` การเปิด index.html ผ่าน file:// โดยตรงอาจโหลด JSON ไม่ได้

## Deploy

GitHub Pages เผยแพร่จาก branch `main` โฟลเดอร์ root โดยอัตโนมัติเมื่อ push การแก้ไข ตั้ง Settings → Pages → Source เป็น Deploy from a branch แล้วเลือก `main` และ `/ (root)`

## ข้อมูล

- รายชื่อและภาพ: Riot Data Dragon รุ่น 16.19.1
- คู่ต่อสู้: CounterStats รวบรวมวันที่ 5 ตุลาคม 2026 จำนวน 7,743 คู่ตามตำแหน่ง
- ข้อมูลเป็น snapshot ไม่อัปเดตอัตโนมัติ
- อัตราชนะของตัวที่เลือกคำนวณจาก 100 ลบอัตราชนะของฝ่ายตรงข้ามตามต้นทาง แสดงจำนวนเต็มตามการปัดเศษของต้นทาง ไม่มีจำนวนเกมให้ประเมินความมั่นใจ
- คู่ที่อัตราชนะเท่ากับ 50% ไม่นำไปจัดเป็นได้เปรียบหรือเสียเปรียบ
- ต้องใช้อินเทอร์เน็ตสำหรับโหลดภาพแชมเปียนและฟอนต์

เว็บแฟนเมด ไม่มีส่วนเกี่ยวข้องกับ Riot Games รูปและชื่อแชมเปียนเป็นทรัพย์สินของ Riot Games สถิติอ้างอิง [CounterStats](https://www.counterstats.net/)
